# MTOrderSteward_EA
MTOrderSteward 是一款功能强大的 MT4 订单管理面板EA，专为主观裁量交易者打造。
它集成一键交易、批量订单管理、鼠标拖拽挂单、风险手数计算、追踪止损以及自定义快捷键功能，大幅提升剥头皮、日内波段交易（外汇/贵金属品种）的操作效率。

重要提示：本EA**不会自动分析行情、自主开仓**，它仅作为手动交易的辅助操作面板。

## 核心功能
1. **一键市价下单、锁仓与反手**
- 一键 BUY（多）/ SELL（空）市价开仓，实时显示买卖报价与点差
- 快捷手数选择：0.01、0.1、0.2、0.5、1、2、5，同时支持自定义手数输入
- 支持直接反手、平仓反手、锁仓、解锁操作
- Magic魔术号筛选：仅管理指定魔术号的订单，和其他EA、手动下单相互隔离

2. **批量平仓 & 分批减仓**
- 按方向平仓：平全部多单 / 平全部空单
- 按盈亏平仓：平全部盈利单 / 平全部亏损单
- 组合条件平仓：平亏损多单、平盈利多单、平亏损空单、平盈利空单
- 比例部分平仓：平仓 1/2、1/3、1/4、2/3

3. **鼠标拖拽挂单**
- 在图表上点击拖拽鼠标，即可挂限价单/突破挂单
- 批量挂单设置：挂单数量、间隔倍数、统一止损止盈点数
- 可选配置：平仓时同步删除挂单 / 账户全清仓时同步删除挂单

4. **止损、止盈、保本、追踪止损**
- 全局统一SL/TP 或 每单独立SL/TP，支持服务端止损
- 保本功能：价格到达预设盈利点数后，将止损移动至开仓价，锁定本金
- 追踪止损：盈利达到设定值后启动，按自定义步长跟随价格移动止损
- 快捷键快速开启/关闭追踪止损、取消止盈

5. **加仓功能（逆势马丁 / 顺势金字塔加仓）**
- 逆势加仓：反向加仓，可配置点数间隔、手数倍率、最大加仓次数
- 顺势加仓：顺着持仓方向金字塔加仓，可配置点数间隔、手数倍率、最大加仓次数

6. **按风险金额自动计算手数（以损定仓）**
- 根据预设风险金额 + 止损点数，自动计算对应的开仓手数
- 内置自定义减仓百分比设置

7. **全功能自定义快捷键**
所有操作均可绑定键盘快捷键：
- 多空双挂单、多空双开仓
- 平多、平空、平盈利、平亏损
- 一键全平、只清亏损、保本
- 分级减仓：20% / 50% / 80%、自定义比例减仓
- 锁仓对冲、市价反手、取消挂单、取消止盈、取消保本

8. **条件自动平仓（循环风控规则）**
设置循环监控的风控触发条件：
- 账户盈亏比例到达阈值时一键全部平仓
- 支持Magic号、金额、订单数量筛选，循环持续监控

9. **实时信息看板**
- 展示账户余额、净值；
- 持仓订单统计（多/空单数、总手数、浮动盈亏）；
- 挂单统计（多/空挂单数量、总手数）。


📋 使用步骤
1. 将 `MTOrderSteward_EA.ex4` 文件放入 MT4 的 `MQL4/Experts` 目录
2. 重启MT4，在导航器（Navigator）面板找到该EA
3. 将EA拖拽到目标品种图表（XAUUSD、EURUSD等）
4. 在面板上调整手数、止损止盈、风险参数
5. 需要键盘交易时，开启快捷键功能
6. 通过面板按钮或者绑定好的快捷键执行交易

🚨 风险警告
一键操作与快捷键响应速度极快，请先在模拟盘充分测试，避免实盘误下单。
本工具仅提供订单操作功能，无法保证交易盈利；所有交易风险由使用者自行承担。
